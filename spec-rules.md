# Qala.fix: правила MVP

Версия 0.2, 16.11.2026. Прототип: `index.html` в этой папке. Пилотный город: Астана (под Astana Innovations Accelerator), Алматы — переключатель в шапке.

## 1. Жизненный цикл точки

| Статус | Как попадает | Что видно |
|---|---|---|
| Собираем подтверждения | Житель добавил жалобу | Пунктирная точка, «1/2 подтверждений» |
| Отправлено, ждём ответа | 2 подтверждения от разных жителей. Опасная категория отправляется сразу | Номер обращения, счётчик «N дней без ответа» |
| Акимат ответил, в работе | Ответ в eOtinish / iKomek | Счётчик без ответа остановлен, идёт «дней в работе» |
| Проверка ремонта | Акимат отчитался ИЛИ первый житель отметил «исправлено» | Прогресс 0/3 |
| Исправлено (зелёный) | 3 голоса «исправлено» от разных верифицированных жителей с геометкой ≤150 м | Галочка, подрядчик, срок гарантии |
| Открыта повторно | 2 голоса «сделано плохо» после зелёного | Возврат в «Отправлено», новое обращение со ссылкой на гарантию, счётчик «открыта повторно ×N» |

2 голоса «не исправлено» во время проверки отклоняют отчёт акимата и возвращают точку в «в работе».

## 2. Цвет

Баллы = опасность + подтверждения + дни без ответа.

- **Опасность:** 3 = опасно для жизни (открытый люк, оголённые провода, провал дороги); 2 = серьёзно (яма, брусчатка/тротуар, освещение, светофор); 1 = неудобство (мусор, ливнёвка, скамейка).
- **Подтверждения** (разные верифицированные жители): 3–9 → +1, 10+ → +2.
- **Дни без ответа** (только в статусе «отправлено»): 15–29 → +1, 30+ → +2.

- **Свой вариант («Другое»):** житель пишет тип сам (до 60 символов) и выбирает опасность 1–3. До проверки модератором (в продукте: ИИ + модератор) опасность считается не выше 2, поэтому свой вариант не краснеет и не уходит в iKomek сразу только из-за выбранной «опасности». После проверки модератор либо переносит жалобу в существующую категорию, либо подтверждает уровень. Частые свои варианты — кандидаты в новые категории.

Итог: **красный** — опасность 3 или ≥5 баллов; **оранжевый** — 3–4; **жёлтый** — ≤2. Неудобство (опасность 1) не поднимается выше оранжевого. **Зелёный** — только по правилу из п. 1.

[Вероятно] Порог 15 дней взят по сроку рассмотрения обращений по АППК РК (15 рабочих дней). Перед запуском проверить у юриста.

## 3. Антинакрутка

- Подтверждать и голосовать может только житель, вошедший через eGov или по SMS. Один человек = один голос на точку.
- Голоса «исправлено» / «сделано плохо» принимаются только с геометкой в радиусе 150 м.
- Новая жалоба той же категории ближе 120 м к открытой предлагается как подтверждение существующей (дедупликация).

## 4. Что настоящее, а что имитация в прототипе

| Функция | В прототипе | Для продукта |
|---|---|---|
| Правила цвета, статусы, пороги голосов | **Работают** | Перенести как есть |
| Карта | Упрощённая схема главных улиц | 2GIS или OSM-тайлы |
| Отправка в eOtinish / iKomek 109 | Имитация, номер выдуман | [Догадка] Публичного API нет: начать с ручной отправки оператором или от имени жителя через его eGov, проверить юридически |
| Ответ / отчёт акимата | Демо-кнопки | Парсинг статуса обращения или кабинет для акимата |
| Верификация eGov / SMS | Переключатель жителя | eGov mobile / OTP по SMS |
| Геометка | Переключатель «рядом / далеко» | GPS телефона + EXIF фото |
| Свой вариант типа | Поле + выбор опасности, пометка «ждёт модератора» | Очередь модерации, ИИ-переклассификация |
| ИИ по фото | Подсказка по ключевым словам из описания | Классификатор изображений, дедупликация по фото и координатам |
| Подписка на точку | Всплывающее сообщение | Push-уведомления |
| Рейтинг районов и подрядчиков | Считается по демо-данным, подрядчики вымышлены | Подрядчики и гарантии из госзакупок (goszakup.gov.kz) |
| Открытые данные | CSV/JSON в окне, копирование | Публичный API + ежедневная выгрузка |
| Сбор из Telegram/СМИ | Метка источника у демо-жалоб | Парсер Telegram-каналов, модерация перед публикацией |
