# Qala.fix

Кликабельный прототип публичной карты городских проблем. Пилот: Астана, Алматы — переключатель в шапке.

- Цвет точки считается по правилам: опасность + подтверждения жителей + дни без ответа.
- Зелёный только после 3 подтверждений жителей с геометкой.
- Отправка в eOtinish / iKomek 109, ответ акимата, eGov-вход и ИИ по фото в прототипе имитируются.

Правила подробно: [spec-rules.md](spec-rules.md). Карта: © OpenStreetMap contributors, Leaflet 1.9.4 (BSD-2).
