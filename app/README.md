# Qala.fix: пилотное приложение

Mobile-first PWA для теста с реальными жителями. Открывается по ссылке, ставится на экран телефона, App Store не нужен.
Адрес после публикации: https://arsylanbaimurat.github.io/qala-fix/app/

Правила цвета и статусов: [../spec-rules.md](../spec-rules.md).

## Что умеет

- Общая карта жалоб (OpenStreetMap) для Астаны и Алматы, фильтр по цвету и «Мои».
- Жалоба: фото с камеры (уменьшается до 1600 px, EXIF и GPS удаляются), место по GPS или пином на карте, категория, свой вариант «Другое».
- Если рядом (≤120 м) уже есть открытая жалоба той же категории, приложение предлагает её подтвердить.
- «У меня тоже»: подтверждения от разных жителей. После 2 подтверждений, а для опасных категорий сразу, жалоба встаёт в очередь на отправку.
- Подача в eOtinish / iKomek 109: готовый текст обращения + поле для номера обращения. С этого момента идёт счётчик «дней без ответа».
- «Уже исправили» / «Не исправлено»: только рядом с точкой (≤150 м). 3 голоса «исправлено» делают точку зелёной.
- «Сделано плохо / снова сломалось»: только со свежим фото и рядом с точкой. 2 голоса открывают точку повторно.
- Модератор: очередь на подачу, проверка «Другого», отметки «акимат ответил / отчитался», скрытие, удаление фото, бан, подрядчик и гарантия.
- Житель может удалить все свои данные из меню.

## Настройка (один раз)

1. Supabase → SQL Editor → вставить [`supabase/schema.sql`](supabase/schema.sql) → Run. Внизу появятся инвайт-коды: `QALA-…` для жителей (200 входов), `MOD-…` для модераторов (3 входа).
2. Supabase → Authentication → Sign In / Providers → включить **Allow anonymous sign-ins**.
3. В [`config.js`](config.js) указаны Project URL и publishable key. Secret / service_role key сюда не вставлять никогда.
4. Свой код вместо случайного: `insert into invite_codes (code) values ('ASTANA2026');` в SQL Editor.

## Раздача жителям

Ссылка + код: «Открой https://arsylanbaimurat.github.io/qala-fix/app/, нажми „Сообщить о проблеме“, введи код QALA-…». На iPhone: Safari → Поделиться → «На экран Домой».

## Проверки

- `supabase/test/test_rules.sql`: проверка правил и прав доступа на локальном Postgres с имитацией Supabase (`test/mock_supabase.sql`).
- Сквозной браузерный тест (создание, дубль, подтверждение, номер обращения, 150 м, зелёный, «сделано плохо» с фото, модератор, удаление данных) прогнан на локальном стенде перед публикацией.

## Ограничения пилота

- Supabase Free: 500 МБ базы, 1 ГБ фото, проект засыпает после 7 дней без активности.
- Данные хранятся во Франкфурте. Персданные (телефон, имя, ИИН) не собираются, пока не будет хостинга в РК.
- Геометку можно подделать на взломанном телефоне. Один голос на устройство, обход через очистку браузера ловит модератор.
